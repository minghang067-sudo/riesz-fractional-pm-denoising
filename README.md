# Riesz Fractional Perona–Malik Image Denoising

This repository accompanies the manuscript on a fractional Perona–Malik diffusion model for image denoising based on the Riesz fractional gradient.

## Repository Status

The source code and experimental materials are currently being organized and have not yet been released.

## Planned Contents

The repository is intended to include:

- Implementation of the proposed fractional Perona–Malik model.
- Fourier pseudospectral discretization and numerical algorithms.
- Scripts and configurations for reproducing the numerical experiments.
- Instructions for reproducing the main tables and figures.

## Availability

The code and reproduction instructions will be uploaded to this repository once the organization and verification process is complete.
